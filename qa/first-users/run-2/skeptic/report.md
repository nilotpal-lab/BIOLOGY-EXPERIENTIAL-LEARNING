## Trust verdict

This is the most provenance-forward analysis tool I have used as a first-time visitor. Every claim I probed had visible evidence behind it: the six "Research source verified" networks each expose a per-dataset record with the original Dryad DOI, the exact source files used, a full citation (including the underlying publication where the web first appeared, e.g. Cohen et al. 2009 PNAS for the Ythan web), an explicit licence (CC0 1.0 with a note that redistribution of the derived network is permitted), and an honest node-unit statement ("groups of organisms, not species"). Demo data is never passed off as research: it carries a persistent "Illustrative demo — not a verified empirical food-web dataset" badge, and the import flow refuses to grant verified status to uncited or self-made data (mine stayed "Research source provided, validation pending"). The methodology page publishes its exact deterministic rules, metric formulas with edge-case guards, a live 70/70 validation suite I can re-run, and it openly documents a place where its own build spec was self-contradictory. Overclaiming is actively counteracted: "structural disruption, not extinction", "recorded relationships only", "no population dynamics", repeated next to the outputs themselves. Control and deletion are sound: imports live only in local storage, are never uploaded, can be removed via a two-step confirmation, and built-in datasets have no delete path at all. Weak spots: the "verified" status is self-asserted by an anonymous "Team 1" with no named authors or contacts (though the DOIs let me check externally), internal VALIDATION test fixtures leak into the user-facing network picker, and there are no terms/privacy pages (minor given the local-only architecture). I would cite this tool in coursework for the underlying datasets (each card gives me a real citation and licence), and I would cite the simulation outputs as what they are labelled: deterministic structural scenarios, not ecological predictions.
